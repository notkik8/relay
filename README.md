# Relay

Relay открывается как одна большая лента. Фотографии, музыкальные записи и кинопостеры перемешаны в адаптивной сетке. У каждого материала есть своя страница с автором, источником, лицензией и лентой похожих находок, которая загружается по мере прокрутки. Сохранять материалы можно без входа.

## Запуск

```bash
docker compose up -d --build --wait
```

Откройте [Relay](http://127.0.0.1:8080). Стартовый каталог входит в сборку, поэтому для обзора, поиска и сохранений ключи не требуются.

### Аккаунты, пины и папки

- Для регистрации нужны уникальный ник, пароль от 15 символов и проверка Cloudflare Turnstile. После регистрации Relay показывает одноразовый код восстановления. Сохраните его, чтобы можно было сменить пароль. В профиле можно указать имя, добавить аватар и описание. Для старых аккаунтов доступен вход по подтверждённой почте или нику.
- Кнопка «Создать пин» принимает JPEG, PNG и WebP до 10 МБ, а также MP3, WAV, OGG, FLAC, MP4 и WebM до 50 МБ. Аудио и видео поддерживают необязательную обложку. Публикации появляются в профиле, общей ленте и разделе «Публикации».
- «В папку» на странице пина добавляет его в личную или публичную папку аккаунта. Папки доступны во вкладке «Папки» профиля. Обычные закладки в «Сохранённом» доступны гостям и хранятся в браузере.

Для публичной регистрации создайте [виджет Turnstile](https://developers.cloudflare.com/turnstile/get-started/) для домена сайта. Укажите `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` и HTTPS-адрес сайта в `RELAY_PUBLIC_URL` в серверном `.env`. Без пары ключей регистрация закрыта.

Для локальной проверки регистрации используйте тестовые ключи Cloudflare.

```bash
TURNSTILE_SITE_KEY=1x00000000000000000000AA \
TURNSTILE_SECRET_KEY=1x0000000000000000000000000000000AA \
  docker compose up -d --build --wait
```

Для проверки прежних сценариев подтверждения почты и нагрузочного скрипта доступен профиль `local-mail` с [Mailpit](http://127.0.0.1:8025). Запускайте его с `SMTP_HOST=mailpit SMTP_PORT=1025 SMTP_SECURITY=plain`.

### Лента и рекомендации

- В каталоге 1 243 изображения, 80 записей и 50 кинопостеров. Источники — Wikimedia Commons, Cleveland Museum of Art Open Access и четыре локальных фрагмента Kevin MacLeod по CC BY 4.0. У каждой карточки есть ссылка на источник и сведения о лицензии.
- Для похожих материалов сравниваются тип, тематика, автор, период, пропорции, теги и слова названия. Для локальных миниатюр также используются палитра и яркость.
- Персональная модель обучается онлайн в браузере. Она учитывает видимость карточки в активной вкладке, задержку курсора, открытия, сохранения и воспроизведение. «Меньше такого» сразу скрывает карточку и применяет сигнал после окна отмены. При перезагрузке страницы лента строится заново с учётом накопленных предпочтений.
- Сохранения и параметры модели хранятся в текущем браузере. Настройки позволяют отключить обучение или сбросить предпочтения с сохранением закладок.
- Локальная сборка включает миниатюры части изображений и четыре MP3-фрагмента. Остальные файлы загружаются с открытых источников по мере просмотра.

Чтобы пересобрать каталог, используйте Python и Pillow из среды бэкенда. Скрипт выбирает файлы по открытым лицензиям, сохраняет атрибуцию и поддерживает необязательное кеширование миниатюр.

```bash
cd backend
uv run python ../scripts/import-discovery.py
```

### Архив подборок

Ранее созданные доски доступны по исходным ссылкам. Старая лента находится в разделе [«Подборки»](http://127.0.0.1:8080/collections). Для просмотра архива с тестовыми досками запустите `CATALOG_DEMO=true SEED_DEMO=true docker compose up -d --build --wait`. Эти два флага регулируют архив и его редактор.

### Рабочие каталоги и HTTPS

Скопируйте `.env.example` в `.env` при первом запуске. Для живых каталогов оставьте `CATALOG_DEMO=false` и задайте `TMDB_API_KEY`. Deezer использует публичный API. Чтобы использовать живой Deezer и тестовые фильмы, задайте `TMDB_DEMO=true`. Документация API Relay доступна на `/api/docs`, схема на `/api/v1/openapi.json`.

На Linux-стенде укажите `RELAY_DOMAIN` с DNS-записью на сервер, уникальный `POSTGRES_PASSWORD` из URL-безопасных символов и `SECURE_COOKIES=true`. Затем запустите профиль HTTPS.

```bash
docker compose --profile https up -d --build --wait
docker compose logs api https
```

Caddy получает сертификат при доступных портах 80 и 443. Порт 8080 предназначен для локального HTTP. База и том файлов доступны сервисам внутри Compose.

Для входа в панель модерации создайте администратора интерактивной командой и авторизуйтесь обычной формой входа.

```bash
docker compose exec api python -m app.seed admin admin@example.org relayadmin
```

### Локальная разработка

Потребуются PostgreSQL, Python 3.12 с uv и Node.js. Задайте `DATABASE_URL` для локальной БД. Из `backend/` выполните:

```bash
uv sync --locked
uv run alembic upgrade head
uv run python -m app.seed demo
CATALOG_DEMO=true uv run uvicorn app.main:app --reload
```

Из `frontend/` выполните `npm ci` и `npm run dev`. Vite проксирует API на `127.0.0.1:8000`. Для проверки регистрации в Vite укажите `RELAY_PUBLIC_URL=http://localhost:5173` и тестовые ключи Turnstile при запуске бэкенда.

### Резервная копия

Копия включает дамп PostgreSQL и том изображений. Команда приостанавливает API на период копирования. Восстановление запускайте с новым именем проекта и свободным HTTP-портом.

```bash
./scripts/backup.sh ./backups/relay-01
COMPOSE_PROJECT_NAME=relay-restore RELAY_HTTP_PORT=8081 ./scripts/restore.sh ./backups/relay-01
```

### Проверки

- Из `frontend/` выполните `npm run lint` и `npm run build`.
- Из `backend/` выполните `uv run ruff check app migrations tests` и `uv run pytest`. Для интеграционных тестов задайте `RELAY_TEST_DATABASE_URL`. Нужна отдельная PostgreSQL и право создавать схемы.
- Добавьте большой набор на изолированном стенде командой `docker compose exec api python -m app.seed demo --large`.
- Из `backend/` запустите `uv run python ../scripts/load.py http://127.0.0.1:8080` на стенде с `CATALOG_DEMO=true` и Mailpit. Скрипт подтверждает тестовый аккаунт через локальную почту и выводит p95, максимум и число ошибок для каждой операции.
- Матрица требований, эксплуатация и порядок показа описаны в [материалах курсовой](docs/coursework.md).

Браузерный сценарий новой ленты можно повторить через Playwright на локальном стенде.

```bash
npm install --prefix /tmp/relay-playwright playwright
/tmp/relay-playwright/node_modules/.bin/playwright install chromium
RELAY_PLAYWRIGHT_DIR=/tmp/relay-playwright/node_modules/playwright \
  node scripts/discovery-smoke.mjs http://127.0.0.1:8080 /tmp/relay-discovery-smoke
```
